## Hard rules — never break these

1. Plain HTML/CSS/JS only. No frameworks, no build step.
2. No Microsoft Forms embedding. The final scene has one button that 
   opens the form URL in a new tab. Nothing else.
3. Mobile is mandatory. Below 768px: vertical stacked layout. Above 
   768px: horizontal scroll-hijacking.
4. PIP animates on a looping CSS timer, never bound to scroll position.
5. All pixel art comes from the uploaded bg-*.png, pip-walk-sheet.png, 
   and coin-spin-sheet.png files. Never hand-draw pixel art in CSS 
   or SVG.
6. Lime green (#39FF6A) only ever appears on a #080B12 dark surface. 
   Never on sky or purple backgrounds.
7. Pixel fonts (Press Start 2P, VT323) for headlines only. Body copy 
   is always plain sans-serif.
